## Publicação

Projeto compatível com Vercel **Other / Static** (sem npm e sem build). `index.html` é a raiz; `styles.css`, `script.js` e `favicon.svg` são arquivos estáticos.

Destinação de domínio: `creator.atlashub.si`, após verificação de DNS e certificado.

## Inscrições

O formulário atual é **pedido por e-mail** (`mailto:`), com texto explicativo explícito. A mensagem só chega à AtlasHub quando o utilizador a envia no seu cliente de e-mail. Antes de anúncios ou tráfego pago, substituir por captura real de leads com consentimento e armazenamento seguro; configurar integração Atlas Access/ARO para matrículas e Pix depois de homologação.
